## Why v1 failed, so you don't repeat it

Static compositions, screens as flat rectangles with drop shadows, transitions
that are opacity fades, and long stretches where nothing on screen moves. It
reads as a beautiful PDF. The target is a film: the camera never stops, the
product is a physical object in space, and type is a moving element rather than
a caption.

## Architecture — this is the important part

Use **GSAP timelines, scrubbed, not played**:

```js
const tl = gsap.timeline({ paused: true });
// ...build the entire 180s timeline declaratively...
window.seek = (t) => { tl.time(t); if (renderer) renderer.render(scene, camera); };
```

This is what unlocks real motion graphics while staying frame-deterministic.
`tl.time(t)` is a pure seek — the same `t` always produces the identical frame,
which is exactly what frame-by-frame capture needs.

For 3D, use **Three.js**, and call `renderer.render()` *inside* `seek()`. Never
start an animation loop.

**Vendor both libraries into `video/vendor/`** (plain `<script>` tags, no build
step, no npm) so rendering never depends on the network mid-capture.

### The one rule that breaks everything if ignored

Every visual must be a pure function of `t`. No CSS animations, no CSS
transitions, no `requestAnimationFrame`, no `Date.now()`, no `Math.random()`
outside a seeded generator. Capture runs ~7fps against a 30fps timeline, so
anything self-animating tears across frames. Also: `img.decode()` never settles
in a backgrounded tab — gate readiness on `load` with a timeout ceiling, never
block on `decode()`.

## Motion language

- **No static frames, ever.** If a shot must hold, the camera still drifts —
  a slow dolly or a 1–2% scale creep. Stillness is death in this genre.
- **Long, heavy eases.** `power3.out` / `expo.out`, 0.8–1.6s. Apple motion is
  weighty and settles. No bounce, no elastic, no overshoot — that reads as toy-
  like and it also violates the brand's own motion spec outside segmented
  controls.
- **The camera does the storytelling.** Dolly in, orbit, rack focus, whip-pan
  between surfaces. Transitions are match cuts and continuous moves, not fades.
- **Depth is mandatory.** Real perspective, parallax layers, depth-of-field blur
  on anything not in focus, soft contact shadows.
- **Screens are objects in 3D space**, tilted and rotating, catching light —
  not `<img>` tags lying flat on the page.
- **Explode and reassemble.** Take the dashboard apart into its layers (sidebar,
  KPI band, chart, cards), float them in Z, then snap them back together. This
  single technique will carry the whole "one system" section.
- **Kinetic type.** Mask-reveal via `clip-path`, per-character stagger at
  20–40ms, type that scales *through* the frame and past the camera. Numbers
  count up on tabular figures.
- **Sound-ready pacing.** Cut on a rhythm of roughly 2.5–4s so a music bed can
  be laid under it later.

## Look

Brand tokens are locked and in `assets/tokens.css`: `--atlas #0B6E4F`,
`--riad #053B2C`, `--mint #7DF2B0`, `--paper #F7F5F0`, `--ink #0A0F0D`. Fonts:
Inter Tight, Instrument Serif, JetBrains Mono.

**Decide the stage colour deliberately.** Apple films are usually near-black
with the product glowing. Kiwi's brand is warm paper. The recommended resolution
is a deep `--riad`-to-black gradient stage for the film, with `--paper` appearing
only *inside* the product screens — cinematic, still on-brand, and it makes the
UI captures glow. This is a film, not a product surface, so it does not conflict
with dark mode being an Ultra-tier feature in the app itself. Confirm before
committing to it.

**Type is roman. Never italic** — `font-style: italic` anywhere is an instant
"generated by a machine" tell and the brand forbids it. No emoji.

## Done means

1. `ffprobe` reports exactly 5400 frames and 180.000000s.
2. Sample ≥12 frames across all scenes and **look at them** — do not assume a
   scene works because it rendered without error.
3. Scrub for blank frames at every transition (v1 shipped a bug where the
   outgoing shot hid before the incoming one faded in, flashing blank 8 times).
4. No frame where nothing is in motion.
5. `node tools/check.js` green before committing.
6. `git add` specific paths immediately before committing — a concurrent session
   works this same tree and will absorb anything left staged.
