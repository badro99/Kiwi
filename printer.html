Pont d'impression

Imprimez reçus, tickets cuisine et étiquettes code-barres sur votre imprimante thermique réseau, directement depuis Kiwi.

Cet appareil ne fait pas tourner le pont

Le pont s'installe sur l'ordinateur du comptoir

Un iPhone ou un iPad ne peut pas faire tourner le pont d'impression, et il n'y a rien à télécharger ici pour lui. Le pont vit sur l'ordinateur (ou la tablette Android) qui est branché à l'imprimante.

Un iPad imprime quand même, par le relais Kiwi : la caisse de l'iPad dépose chaque impression sur le relais, et le pont du comptoir la récupère et l'imprime.

  1. Sur l'ordinateur du comptoir, ouvrez cette page (kiwi-os.com/printer.html), téléchargez le pont et lancez-le. Il faut la version 1.4.0 ou plus récente.
  2. Dans Kiwi, sur l'iPad : Imprimantes → Relais Kiwi → Associer un pont, puis générez le code à 6 chiffres.
  3. Saisissez ce code dans le pont, sur l'ordinateur du comptoir. L'association se fait une seule fois.
Recherche du pont sur cet ordinateur…
Qu'est-ce que c'est ?

Un petit programme à installer sur l'ordinateur de la caisse. Kiwi lui envoie les impressions et il les transmet à votre imprimante. Il tourne discrètement en arrière-plan et n'écoute que sur cet ordinateur · aucune donnée ne sort de votre machine.

2 · Lancer
  1. Double-cliquez le fichier téléchargé kiwi-printer-bridge-win.exe.
  2. Si « Windows a protégé votre PC » apparaît : Informations complémentaires → Exécuter quand même. Cette version n'est pas encore signée numériquement, et c'est la seule raison de cet avertissement : Windows ne peut pas vérifier l'éditeur. Ne continuez que si vous avez téléchargé le fichier depuis cette page Kiwi.
  3. Laissez la fenêtre ouverte. Si vous la fermez, l'impression s'arrête.
  4. Démarrage automatique (recommandé en boutique). Sinon il faut relancer le pont à chaque redémarrage du PC. Win + R → shell:startup → dans le dossier qui s'ouvre, créez un fichier kiwi-printer.cmd contenant :
    @echo off set KIWI_BRIDGE_PORT=9110 start "" /min "%USERPROFILE%\Downloads\kiwi-printer-bridge-win.exe" Adaptez le chemin si vous avez déplacé le .exe. Le pont démarrera seul, en fenêtre réduite.
  5. Si le pont ne démarre pas (la fenêtre s'ouvre puis se referme aussitôt) : le port 9110 est déjà pris par un autre logiciel. Dans le .cmd ci-dessus, remplacez 9110 par 9111 (ou 9112 / 9113 / 9114) · Kiwi cherche automatiquement sur cette plage.
  1. Double-cliquez le fichier téléchargé · il se décompresse en Kiwi Printer. Glissez-le dans votre dossier Applications.
  2. Double-cliquez Kiwi Printer. macOS affiche « développeur non identifié » ou « Apple ne peut pas vérifier ». Cette version du pont n'est pas encore notariée par Apple, donc macOS ne peut pas la valider à votre place, et nous ne pouvons pas vous demander de lui faire confiance sans réserve : ne passez à la suite que si vous l'avez téléchargée depuis cette page Kiwi. Cliquez OK.
  3. Ouvrez Réglages Système → Confidentialité et sécurité. Descendez tout en bas : à côté de « Kiwi Printer a été bloqué… », cliquez Ouvrir quand même, puis Ouvrir. C'est nécessaire une seule fois.
  4. Aucune fenêtre ne s'ouvre · c'est normal. Kiwi Printer tourne discrètement en arrière-plan. (Sur un Mac Apple Silicon, macOS proposera d'installer Rosetta au premier lancement · cliquez Installer.)
  5. Empêcher la veille (pour relayer les iPad) : dans un terminal, lancez caffeinate -s & ou dans Réglages Système → Batterie / Écran, empêchez la suspension automatique. Laissez le capot ouvert.
Option avancée · installation en ligne de commande

Pour les personnes à l'aise avec le terminal : ce script installe le pont comme service (LaunchAgent) qui survit aux redémarrages. Il s'exécute avec vos droits, lisez-le avant de le lancer : install-macos.sh.

curl -fsSL https://raw.githubusercontent.com/badro99/Kiwi/main/bridge/install-macos.sh | bash

  1. Lancement :
    chmod +x ~/Downloads/kiwi-printer-bridge-linux && ~/Downloads/kiwi-printer-bridge-linux
Option avancée · installation en service (Raspberry Pi / Debian / Ubuntu)

Ce script s'exécute en administrateur (sudo) et installe le pont comme service systemd (Restart=always) : il redémarre seul. Lisez-le avant de le lancer : install-linux.sh.

curl -fsSL https://raw.githubusercontent.com/badro99/Kiwi/main/bridge/install-linux.sh | sudo bash

  1. Téléchargez Kiwi Print Bridge avec le bouton ci-dessus. Si Android le demande, autorisez Chrome à installer des applications inconnues, puis installez l'APK.
  2. Ouvrez l'application. Autorisez les notifications : la notification permanente confirme que le pont reste actif.
  3. Dans Kiwi → Imprimantes → Relais Kiwi → Associer un pont, générez le code à 6 chiffres, puis saisissez-le dans Kiwi Print Bridge.
  4. Dans Paramètres Samsung → Applications → Kiwi Print Bridge → Batterie, choisissez Sans restriction. Le pont redémarrera automatiquement avec la tablette.
  5. Configurez l'adresse IP de chaque imprimante dans Kiwi. Pour vérifier le réseau immédiatement, saisissez aussi l'IP dans l'application et imprimez un ticket test.

Une fois lancé, revenez dans Kiwi → « Connecter une imprimante » → saisissez l'adresse IP de votre imprimante et lancez un ticket test. Le voyant passe au vert.
