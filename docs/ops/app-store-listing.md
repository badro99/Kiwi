## App Privacy

Data used to track you: **No**. Every type below is **linked to the user**,
purpose **App Functionality**; the two marked with † also have **Analytics**.
This is the same list as `app/ios/App/App/PrivacyInfo.xcprivacy` (21 types)
and the table in `APP_STORE.md` §4, which says why each one is there.

- Contact Info: Name, Email Address, Phone Number, Physical Address
- Health & Fitness: Health
- Financial Info: Payment Info, Other Financial Info
- Sensitive Info: Sensitive Info
- User Content: Emails or Text Messages, Photos or Videos, Audio Data, Customer Support, Other User Content
- Search History: Search History †
- Identifiers: User ID, Device ID
- Purchases: Purchase History
- Usage Data: Product Interaction †
- Diagnostics: Crash Data, Other Diagnostic Data
- Other Data: Other Data Types

Not collected: precise or coarse location, contacts, browsing history,
advertising data, gameplay content, fitness.
