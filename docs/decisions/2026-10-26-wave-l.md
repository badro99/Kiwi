Valeurs limites : 0, 0.01, 0.50, 12, 12.50, 999999.99. Suite enregistrée dans tools/check.js, aucune assertion limitée au texte source.

Preuves rouges puis vertes (restauration des fichiers après chaque expérience) :

- Carnet : remplacement temporaire par HEAD, test rouge sur 0.50 affiché 1 ; restauration et test vert.
- Répertoire : même expérience sur clients-directory.js, même échec ; restauration et test vert.
- Historique achat : rétablissement temporaire du Math.round original sur les mappings, test rouge sur 0.5 ; restauration et test vert.
- Historique retour : rétablissement du mapping original du retour seul, test rouge sur 0.5 ; restauration et test vert.
- Arabe sans KiwiNumber : rétablissement du choix FR pour AR dans le helper, comparaison au format ar-MA rouge ; restauration et test vert.
- CSV : le code de HEAD exportait déjà c.spend brut, sans appeler fmt. Aucun défaut de précision reproduit sur cette voie ; test de non-régression sur 1234.50, sortie 1234.5 sans groupement, désormais via le helper commun.
