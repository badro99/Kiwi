Le relevé initial compte 3 493 écritures candidates sur 411 fichiers. Après correction : 3 489. Un emplacement conditionnel compte une fois, même s’il contient plusieurs messages. Le garde parcourt assets/** propriétaire et les scripts intégrés des HTML racine, suit les alias scalaires non ambigus, inspecte les gabarits, attributs accessibles, titres et helpers toast/modal/drawer. Les chaînes traduites explicitement sont écartées ; la mutation DOM différée ne dispense pas du garde. Les styles et balises sans texte visible sont écartés.

Limites ouvertes : analyse conservatrice, sans propagation interprocédurale, résolution des propriétés métier ou distinction automatique certaine entre une donnée métier et un libellé. Des constructions HTML fragmentées peuvent compter comme candidates. Les alias de helpers non reconnus, textes passés indirectement entre fonctions et valeurs affectées après déclaration nécessitent encore une analyse plus poussée. Ce relevé ne prouve donc pas l’exhaustivité de tous les flux dynamiques. Les modules gelés restent comptés mais inchangés.
