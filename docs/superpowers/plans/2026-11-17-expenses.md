# Dépenses (owner expense ledger) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A per-merchant, owner-only "Dépenses" page in the dashboard that shows money in, money out (typed expenses + till cash-outs, auto-categorised), what is left, and lets the owner add, scan, edit and delete expenses.

**Architecture:** A pure ES-module engine (`assets/expenses/engine.js`) does every calculation. Two owner-only Pages Functions feed it: `/api/expenses/summary` (server-truth net takings per business day + the month's till cash-outs) and `/api/expenses/receipt` (private R2 receipt photos). Expenses live in the existing `expenses` store document, now owner-only on the server. One `<script type="module">` tag loads the page.

**Tech Stack:** Vanilla JS (ES modules on the dashboard), Cloudflare Pages Functions + D1 + R2 (`MEDIA`), Workers AI via the existing `/api/ai/expense-ocr`, node test files in `tools/`, puppeteer via `tools/browser-trace.mjs`.

**Spec:** `docs/superpowers/specs/2026-11-17-expenses-design.md`

## Global Constraints

- Module key `expenses`; ON only when `features.expenses === true` (absent = OFF), everywhere.
- Owner (account session that owns the store) or a named Kiwi operator only. Paired till, employee sessions (manager included) get 403 on the document and both routes.
- `dashboard.html` gains exactly one `<script>` tag. No new stylesheet `<link>`; CSS ships as a JS string.
- Every new file < 2 500 lines and ≤ 12 foreign globals (`tools/coupling-ratchet-test.mjs`).
- Amounts are integer cents everywhere; MAD shown via `KiwiNumber.format` when present.
- Business day: 05:00 cutoff in the merchant zone (`functions/api/_business-day.js`).
- Copy: FR / EN / AR, no U+2014 em dash, no italics, Material Symbols icons only (`fill="currentColor"`, `viewBox="0 -960 960 960"`), tokens from `assets/tokens.css`, liquid lens on the month switcher.
- Stamps via `node tools/bump-stamp.js`; routes via `node tools/build-fast-routes.mjs`; every new test named in `tools/check.js`.
- Full gate before push (money + auth). Never write to prod D1.

## Review Focus

1. A till cash-out the owner "completes" must disappear as a raw row and count once (engine test `dedupesCompletedCashOut`).
2. "Dépôt banque" cash-outs are never expenses, whatever their case/accents (engine test `excludesBankDeposit`).
3. A month with no expenses and no cash-outs renders the honest first-use state, never zeros dressed as data (browser test `emptyMonth`).
4. An expense deleted on one device does not come back from another device's older copy (engine test `mergeKeepsTombstones`).
5. A manager session or a paired till cannot read or write `expenses` (API test `managerAndTillRefused`).

### Task 1: The engine

**Files:**
- Create: `assets/expenses/engine.js`
- Test: `tools/expenses-engine-test.mjs` (named in `tools/check.js`)

**Interfaces:**
- Produces (named ES exports):
  - `CATEGORIES: string[]` = `['meat','produce','grocery','drinks','hygiene','packaging','supplier','energy','rent','repairs','transport','staff','marketing','equipment','taxes','other']`
  - `classifyReason(text: string) -> category` (FR, Darija-Latin, AR keywords; unknown → `'supplier'` when it contains achat/fournisseur, else `'other'`)
  - `isBankDeposit(text: string) -> boolean`
  - `normalize(doc) -> { list: Expense[] }` (drops malformed rows, clamps cents to 0..1e9, keeps tombstones)
  - `mergeDocs(mine, theirs) -> { list }` (union by `id`, higher `updatedAt` wins, tombstone wins on tie)
  - `cashOutRows(events, expenses) -> Row[]` (movement `out` only, bank deposits dropped, events whose id is some live expense's `cashEventId` dropped; row `{ id:'cash:'+id, date, amountCents, category, guessed:true, note, actorId, source:'till' }`)
  - `monthView({ month:'YYYY-MM', today:'YYYY-MM-DD', expenses, cashOuts, salesDays:[{day,salesCents}], charges?, salaries? }) -> { inCents, outCents, leftCents, byCategory:[{category,cents,count,prevCents?}], byDay:[{day,outCents}], rows:Row[] (newest first), fixed:{ chargesCents, salariesCents, advancesCents, afterFixedCents } | null }`
  - `toCsv(rows, lang) -> string` (header `date,category,supplier,method,amount,vat,source,receipt`, `;`-free, amounts `123.45`)
  - `Expense` = `{ id, date, amountCents, category, method:'cash'|'card'|'transfer'|'cheque'|'other', supplier, note, vatCents, receiptKey, cashEventId, source:'manual'|'scan'|'till', createdAt, updatedAt, deleted }`

**Interfaces:**
- Produces:
  - `_owner.js`: `export async function expensesReader(request, env, merchant) -> boolean` = `ownerMerchant(request, env, merchant) === merchant || isOperator(request, env)`.
  - `GET /api/expenses/summary?merchant=&month=YYYY-MM` → `{ ok, month, zone, cutoff, salesDays:[{day,salesCents}], cashOuts:[{id, occurred_ts, day, movement_amount_cents, movement_reason, actor_id}] }`. Sales = `SUM(COALESCE(amount_cents, amount*100))` of non-voided rows grouped by `businessDate(ts, cutoff, zone)`; cash-outs = `movement_kind='out'` in the month's business window. 403 `{error:'owner-required'}` otherwise; bad month → 400.
  - `POST /api/expenses/receipt?merchant=&id=<expenseId>` raw `image/jpeg|png|webp` body ≤ 4 MB → stores `private/expenses/<merchant>/<id>.jpg` in `env.MEDIA`, returns `{ ok, key }`. `GET` same query → streams it with `Cache-Control: private, max-age=3600`. No `MEDIA` → 503 `{error:'no-media'}`. Id must match `/^[A-Za-z0-9_-]{6,64}$/`.
  - Store: `GET/POST /api/store` with `feature=expenses` → 403 `{error:'owner-required', feature}` unless `expensesReader`.
